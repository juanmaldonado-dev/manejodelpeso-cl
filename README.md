# Manejo del Peso.cl

Sitio web oficial de **Manejo del Peso.cl | Programa Médico**.

## Objetivo

Landing informativa para presentar un programa médico de manejo del peso y salud metabólica orientado a adultos, con un enfoque de:

- evaluación clínica;
- plan individualizado;
- seguimiento médico;
- comunicación compatible con campañas de Meta sin promocionar medicamentos de receta ni prometer resultados específicos.

## Estructura

- `index.html` — página principal
- `styles.css` — identidad visual y diseño responsive
- `script.js` — navegación móvil e interacciones
- `privacidad.html` — política de privacidad
- `assets/logo.svg` — logo
- `assets/favicon.svg` — favicon
- `assets/og-image.svg` — imagen social
- `CNAME` — dominio personalizado `manejodelpeso.cl`
- `robots.txt` — directivas para buscadores
- `sitemap.xml` — sitemap

## Publicación en GitHub Pages

En GitHub:

1. Abrir **Settings → Pages**.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar **main** y carpeta **/(root)**.
4. Guardar.
5. Confirmar que el dominio personalizado sea `manejodelpeso.cl`.
6. Configurar los registros DNS del dominio según los valores que muestre GitHub Pages.
7. Cuando el certificado esté disponible, activar **Enforce HTTPS**.

## Pendientes antes del lanzamiento definitivo

- agregar nombre y credenciales verificadas del profesional;
- conectar un canal de agendamiento o WhatsApp Business si se decide utilizar;
- reemplazar el correo Gmail por un correo del dominio cuando esté disponible;
- revisar la política de privacidad si se incorporan formularios, analítica o Meta Pixel.
